隐私政策

最后更新：2026 年 9 月 / September 2026

一、核心承诺

你的图片不会离开你的设备。本站所有工具的处理（解码、重绘、编码、人脸检测） 均在访问者的浏览器中于本地完成，不会上传、存储或传输到任何服务器。

二、我们收集哪些信息

本站工具本身不收集任何个人信息：

  • 不收集你处理过的图片内容
  • 不收集姓名、邮箱、电话等身份信息
  • 不要求注册或登录
  • 不设置用于追踪的 Cookie（第三方广告可能有独立 Cookie，见下条）

三、第三方广告

本站及各工具页可能展示第三方广告（如 Google AdSense）。这些服务商可能会使用 Cookie 展示个性化广告，并收集 IP 地址、浏览器类型等技术信息。

你可以访问 Google 广告设置 管理个性化广告偏好，或通过 aboutads.info 退出。

四、Cookie 说明

本站自身不使用 Cookie。在浏览器中禁用 Cookie 不影响各工具的核心功能。

五、日志与统计

本站托管于 GitHub Pages，GitHub 可能记录访问日志，详见 GitHub 隐私声明。 本站自身不额外收集访问日志。

六、关于 EXIF 信息

工具在重新编码图片时会丢弃原图的 EXIF 元数据（含 GPS 位置），有利于保护你的位置隐私。

七、儿童隐私

本站面向一般用户，不针对 13 岁以下儿童设计，也不会有意收集儿童个人信息。

八、政策更新

本隐私政策可能更新，更新后会在本页标注新的生效日期。

九、联系方式

如有疑问，可通过 GitHub 联系。
