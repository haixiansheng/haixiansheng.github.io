About

A set of free image tools that run entirely in your browser

Why we built these

Most "free online image tools" work by uploading your image to their servers and sending the result back. That's fine for public stock photos — but if you're handling screenshots, IDs, contracts or private photos of people, handing them to an unknown server is a privacy risk in itself.

So we built a set of tools with no server at all. Everything runs in your browser and your images never leave your device. This isn't a promise not to store them — there is physically nowhere to store them.

Available tools

  • Face Mosaic — automatic face blurring with three effect styles
  • Image Compressor — up to 90% smaller, with quality and target-size modes
  • Image Converter — PNG / JPG / WebP / BMP with proper transparency handling

All free, no sign-up, no watermark, no usage limits.

How it works

  • Canvas API — decode, redraw and re-encode images locally
  • Blob / toBlob() — produce downloadable files without a server round-trip
  • On-device face detection (face-api.js) — the model ships with the page and runs locally

No server-side computation is involved, so everything works offline after first load.

Verify it yourself

Press F12 → Network panel → clear it → process an image. If you only see the page's own static assets (html/css/js), your image was not uploaded. The test cannot be faked.

Even more direct: load a tool, disconnect your network, then process an image. If it still works, the computation is local.

Privacy bonus

Re-encoding drops the original EXIF metadata (including GPS coordinates) as a technical side effect — which protects your location privacy.
