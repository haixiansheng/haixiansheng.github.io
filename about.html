关于本站

一组纯浏览器本地运行的免费图片工具

为什么做这些工具

网上大多数"免费在线图片工具"，工作方式都是：把你的图片上传到它们的服务器， 处理完再传回来。对公开素材图无所谓，但如果你处理的是截图、证件、合同、 含人脸的私人照片，把图片交给陌生服务器本身就是一次隐私风险。

所以我们做了一组没有服务器的工具：所有处理都在你的浏览器里完成， 图片从始至终不离开你的设备。这不是"承诺不存储"——而是技术上根本没有地方存。

现有工具

  • 人脸马赛克 —— 自动识别人脸并打码，三种效果可选
  • 图片压缩 —— 最高省 90% 体积，支持目标大小模式
  • 图片格式转换 —— PNG / JPG / WebP / BMP 互转，透明背景智能处理

全部免费、无需注册、无水印、不限次数。

技术原理

这些工具依赖现代浏览器的几个能力：

  • Canvas API —— 在本地解码、重绘、重新编码图片
  • Blob / toBlob() —— 生成可下载的文件，无需服务器中转
  • 人脸检测模型（face-api.js）—— 在本地推理，模型文件随页面一起加载

整个流程不涉及任何服务器端计算，断网也能正常使用。

怎么自己验证

不用相信任何宣传，30 秒就能查：按 F12 打开开发者工具 → Network 面板 → 清空 → 处理一张图片。如果只看到页面自身的静态资源 （html/css/js），说明图片没有被上传。这个方法无法作弊。

更直观的办法：加载完页面后断开网络，再处理一张图。能正常用就说明计算全在本地。

关于隐私

重新编码图片会丢弃原图的 EXIF 元数据（含 GPS 位置）， 这是技术实现的副产品，同时保护了你的位置隐私。
